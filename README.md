# ZEUS - Solana Trading Bot

Bot de trading para Pump.fun na Solana.

## Quick Start
1. Execute o SQL no Supabase
2. `cd zeus-bot && npm install && npm start`
3. `cd zeus-hub && vercel`

## Features
- Auto-gera wallet
- Detecta tokens Pump.fun
- Dashboard real-time
- API REST
